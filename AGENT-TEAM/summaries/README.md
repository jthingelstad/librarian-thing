# summaries/

Committed ISO-week rollups, one per week that had activity: `YYYY-Www.md`. A
summary is the durable "how the Librarian evolved" record — what shipped, what
is being watched, and what needs Jamie — distilled from git, issues, and the
run notes. Unlike per-run notes, these are the record a future reader starts
from; keep them short and decision-relevant.
